# 小课堂：乐理、节奏、效果

## 用户的原话和决定

- “这个项目目前似乎没有乐理方面的学习内容，要掌握这类乐器，必要乐理知识还是需要的，不用很深，教程要有趣，轻松，容易接受，不枯燥。”
- “乐理，节奏，以及各类 fx 效果的培训。”
- 放在哪：**两处都要**。新增一个「小课堂」放全套，随时能进、能查；主线每一章再挑最必要的一两关放进闯关地图。
- 先做哪些：**三条线各先做 3–4 关**，让他尝尝形式对不对、够不够轻松，再铺开做完。

现状（提出时）：乐理其实嵌在第 1–3 章的课里（拍子、小节、音阶、根音和五音、和弦），但是散的，没有一个地方能轻松地成套学、随时查；节奏只有“照着打”，没有听辨和数拍；效果完全没有（原计划在还没做的第 7 章）。

## 每一关长什么样

一关 3–5 分钟，只讲一个概念，固定四步：

1. **一句话**：用他懂的话说这是什么。优先用他打碟的经验和生活里的比方。
2. **玩一玩**：一个能动手的东西，先玩，玩出感觉了再给它起名字。
3. **试一试**：一个小挑战（听一听选一个、照着做一下）。答错不扣分，马上能再来；星星按这一步的表现给。
4. **用在机器上**：真机上的一个小动作。真机镜像认得出就自动打勾；没带机器就在模拟机上做。

写法上的规矩：

- 短句、口语。术语不打头：先有体验，再说“这个叫切分”。
- 每关最后有一句“带走的话”。
- 不出现五线谱（这台机器用不到），不出现大段文字，不先下定义。
- 不是考试。

## 三条线

标 ★ 的是首批要做的。

### 乐理线

| 关 | 名字 | 讲什么 | 玩什么 |
|---|---|---|---|
| ★ T1 | 四个一组 | 拍子和小节：为什么音乐总是 4 个一组 | 一条会走的 16 步格子，拍手对上重音 |
| T2 | 把一拍切开 | 四分、八分、十六分 | 同一个拍子切成 1 / 2 / 4 下 |
| T3 | 不踩在拍子上 | 反拍和切分：让人想动的地方 | 把一下鼓从正拍挪到缝里，听区别 |
| T4 | 摇一摇 | 摇摆是怎么回事 | 一个滑条，从笔直到摇晃 |
| ★ T5 | 高和低 | 音名、八度：同一个音在高处和低处 | 一排键，高八度听起来“是它又不是它” |
| T6 | 一格和两格 | 半音和全音 | 在 12 个格子里数步子 |
| ★ T7 | 亮和暗 | 音阶；大调亮、小调暗 | 同一段小旋律，一键切大调 / 小调 |
| T8 | 怎么按都不难听 | 五声音阶 | 五个键随便按，配上伴奏都好听 |
| T9 | 两个音的距离 | 三度甜、五度稳 | 两个音一起按，换距离听味道 |
| ★ T10 | 三个音叠起来 | 和弦；大的亮、小的暗 | 叠积木：隔一个拿一个 |
| T11 | 四个和弦走天下 | 最常见的和弦进行 | 四块牌子换顺序，听出熟悉的歌 |
| T12 | 整首歌搬个家 | 调和移调 | 把一段旋律整体挪高挪低 |
| T13 | 一首歌的形状 | 4 / 8 / 16 小节，铺垫和高潮 | 拖动几个段落，摆出能量曲线（他打碟时熟悉的东西） |

### 效果线

2026-11-10 做首批之前，对照 `docs/seqtrak-operation-reference.md`（3.11、3.12、3.15.1）核对过这台机器实际有的效果，清单按它改成了下面这样（原先是 10 关，现在 11 关）。

| 关 | 名字 | 讲什么 | 这台机器上在哪 |
|---|---|---|---|
| ★ F1 | 干的和湿的 | 效果是什么：原声和加了效果的声音，一键对比 | [MASTER/SINGLE] 开关拨到 MASTER，[FX LEVEL] 触摸条管加多少，[CLEAR FX] 回到原声 |
| ★ F2 | 把声音捂住 | 低通滤波器 | 每条轨道自己的滤波器：右边 4 个旋钮翻到第 2 页，第 3 个（Index 上 FILTER 亮） |
| F3 | 把低音抽走 | 高通滤波器 | [HIGH PASS] 触摸条：作用于全部轨道，手一离开就复原 |
| F4 | 那一声“喵” | 共鸣 | 第 2 页的第 4 个旋钮（RESONANCE） |
| ★ F5 | 房间有多大 | 混响 | [FX] 旋钮转到 REVERB 这一类（8 个预设），[FX LEVEL] 管量 |
| ★ F6 | 踩在拍子上的回声 | 延迟 | [FX] 旋钮转到 DELAY 这一类（8 个预设，第 1 个是一拍回一次） |
| F7 | 弄脏它 | 失真 | [FX] 旋钮的 DISTORTION 类（WAVE FOLDER、AMP SIMULATOR、BIT CRUSHER、DIGITAL TURNTABLE） |
| F8 | 让底鼓先走 | 压缩和躲闪：那种一吸一吸的感觉 | [FX] 旋钮的 COMP、DUCKER 两类 |
| F9 | 切碎了重复 | 重复器 | [REPEATER] 触摸条：手一离开就复原 |
| F10 | 晃动的声音 | 调制：合唱、镶边、颤音 | [FX] 旋钮的 MODULATION 类 |
| F11 | 做一次铺垫 | 现场怎么把气氛推上去，再一把放开 | [HIGH PASS] + [REPEATER]，最后可以用 OTHER 类里的 VINYL BREAK（唱机刹车）收 |

核对下来的几件事：

- **机器上的效果有三层**：每条轨道自己的（一个单轨效果 → 滤波器 → 两段均衡）；全部轨道共用的两路“发送”（混响、延迟，每条轨道各送多少）；总输出上的（主效果 → HIGH PASS → REPEATER → 压缩 → 五段均衡）。[FX] 旋钮选的是 8 类 × 8 个预设；[MASTER/SINGLE] 开关决定它管整台机器还是只管当前选中的那条轨道。首批几关都用 MASTER。
- **改了的**：F8 原来叫“把大小声压平（压缩）”。总输出上那个压缩器在机身上调不了（只能在官方 App 里），机身上摸得到的是 [FX] 旋钮里 COMP 和 DUCKER 两类预设，所以改成讲这两样。
- **加了的**：F10「晃动的声音」。机器上 MODULATION 是整整一类（合唱、镶边、相位、自动声像、颤音、哇音、环形调制），原清单里没有。原来的 F10「做一次铺垫」顺延成 F11，并加上唱机刹车。
- **没排进来的**：均衡（轨道上的两段在进阶第 3 页，总输出的五段只能在 App 里调）；OTHER 类里其余几种（TALKING MODULATOR、ROTARY SPEAKER、SLICE 等）。要不要加，等用户试完首批再定。
- **手册没写清、课文里因此不下断言的**：触摸条哪一端是最大；轨道滤波器那个旋钮往哪边是低通（它是“低通—原样—高通”连在一起的）；单按一次 [OCTAVE]、[SCALE]、[SWING] 走多少。课文都写成“转着 / 滑着听”“看右边那列小灯”。
- **混响和延迟在机器上有两条路**：[FX] 旋钮的 REVERB / DELAY 类（F5、F6 用的是这条，只要一个旋钮和一条触摸条），以及发送效果（每条轨道的发送量在 Sound Design 进阶第 3 页或 Mixer 模式里）。后一条留给第 7 章。

“用在机器上”那一步只写手册里确认过的操作。

## 效果实验台

效果线每一关的“玩一玩”都在它上面：

- 一段一直循环的鼓和贝斯（用应用自己的合成声音，不带音频文件），经过一个效果，再出来。
- 一两个大旋钮或滑条（给手指用，够大），一个“原声 / 加效果”的对比开关，一块实时的画面（让人看见声音变了）。
- 效果全部用浏览器自带的 Web Audio 做，不带任何音频文件。
- 做成独立的模块，小课堂和以后的第 4、7 章都能嵌。

## 首批做成了什么样（2026-11-10）

12 关已做，三条线现在一共 32 关（乐理 13、节奏 8、效果 11），其余 20 关在列表里显示“还没开放”。**用户还没试过，下面都是我的做法，不是他确认过的。**

- **在哪**：`#/classroom`（列表）和 `#/classroom/<关的 id>`（一关），左边导航栏有「小课堂」。内容在 `public/js/content/classroom.js`，页面 `views/classroom.js`，玩具 `classroom-toys.js`，“用在机器上”那一屏 `classroom-bench.js`，效果实验台 `fxlab.js`，样式 `public/css/classroom.css` 和 `fxlab.css`（由模块自己插入页面）。
- **“一句话”不单占一屏**：一进关，那句话就在右边由教练说出来，左边直接是能玩的东西。他是先玩再看字的人，为一句话多点一下不值得。顶上的四步里“一句话”一进来就是打了勾的。
- **名字后说**：玩具被动过三下之后，右边才出现“这个叫……”。
- **星星**只看“试一试”：听辨类答对 3 题过关，一次没错 3 颗、错一次 2 颗、再多 1 颗；拍垫子的看稳不稳；跳过这一步也能学完，先给 1 颗。
- **16 个格子都画成机器上那两排方键的样子**（上排 1–8，下排 9–16），认图和认机器是一回事。
- **“用在机器上”那一屏**：接着真机时是真机镜像（整台摆出来，只是镜子）；没接真机时是模拟机，放大到方键有 47 像素以上、面板可以左右滑。效果关在没接真机时用的是另做的一台“效果模拟机”（现有的模拟机不会做效果）：[FX] 旋钮、[FX LEVEL]、[CLEAR FX]、4 个旋钮的翻页和每条轨道的滤波器都是真的会响的。
- **真机上哪些能自动打勾**：播放 / 停止、选轨、弹键、八度、音阶、鼓轨的格子、摇摆、速度、切到 CHORD、和弦——都走镜像现成的识别。节拍器开没开、[MASTER/SINGLE] 开关、[FX] 旋钮转到了哪一类，机器不上报，只能自己点按钮。动 [FX LEVEL]、转滤波器旋钮、翻页，按官方的控制器表和实测到的参数上报做了识别，**但没有人在真机上试过**，认不出时旁边有“我做了”。
- **进度**存在进度文件的 `classroom` 字段里（`{ T1: { done, stars, at, times } }`），学完一关也算当天练过。
- **经验值、徽章、地图上的小关**（2026-11-10 接上的，规则写在 `docs/design-direction.md` 的“经验值、等级、徽章”一节）：学完一关 1 星 20 / 2 星 25 / 3 星 30 经验，从 `classroom` 字段算出来，再学一遍不重复给；徽章“三线齐亮”= 三条线各学完一关；首页地图上第 1 章前挂 T1 和 R1、第 2 章前挂 T5 和 T7、第 3 章前挂 T10（对应关系在 `public/js/classroom-minis.js`，以后开放了新关想挂，改那一张表就行）；「设置」里的“清空学习进度”会把这个字段一起清掉。数和徽章是做的人定的，用户没确认过。
- **走查**：`public/js/dev/walk-classroom.js` 能把一关从头自动走到尾（玩、答题、拍垫子、在模拟机或假真机上做动作）。两种情况下 12 关都走通了，没有报错；1024 × 768 和 1180 × 820 下每一屏都量过，没有要滚动的、没有出屏幕的、没有小于 44 像素的按钮。

没法验证、要用户来判断的：声音好不好听、效果像不像（只量到“加了效果后高音确实没了 / 多出来的那一路确实有声音”）；文案够不够轻松；每关是不是三五分钟；真机上效果那几步的自动识别。
