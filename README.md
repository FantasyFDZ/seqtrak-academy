# SEQTRAK Academy

Yamaha SEQTRAK 的互动教学应用：课程 + 节奏音游 + AI 陪练。面向零基础，目标是走完“节奏 → 旋律与音色 → 采样 → 编曲 → 现场”，最终掌握 5–10 首曲目。

## 怎么启动

机器用 USB-C 线接在 Mac 上，然后：

- **双击 `start.command`**，它会启动本地服务并用 Chrome 打开 <http://localhost:4747>；或者
- 在终端里运行 `node server/server.mjs`，再用 Chrome 打开同一个地址。

第一次打开时点左边导航栏的「设备」（上面有一颗橙色的灯），在浏览器的权限窗口里选“允许”（需要允许 MIDI 设备，包括 SysEx）。没接机器也能用：所有练习都可以用电脑键盘代替。

要求：Node 20+，Chrome 或 Edge（Safari 不支持 Web MIDI）。没有任何 npm 依赖。

## AI 教练：啾啾

教练是一只红嘴相思鸟，叫**啾啾**（2026-11-13 定的；之前叫“阿拍”，是一颗旋钮的脸）。全应用只有一只，在屏幕上飞来飞去：平时蹲在左边导航栏最下面它的窝里，页面上给它留了位置（首页的问候卡、结算卡、庆祝卡）就飞过去，动手的步骤里飞到要按的键上方悬停着指给你看，做偏了摇摇头，做完一步翻个跟头。不同的叫声表示不同的情绪，跟“界面音效”开关走，音游打着的时候不出声、只在窝里跟着拍子点头。
和它说话不是聊天窗口：点一下它（或它的窝），它问“啾！怎么啦？”，下面是按现在场合挑的几个选项（课上：这步没懂 / 我卡住了 / 示范一下；有机器的图时：这个键是干嘛的？；打完一局：点评刚才那局；首页：今天怎么练？），打字问是最后一个选项。即时回答一句一句从它身边冒出来，说到机器上的哪个键它就飞过去；“这个键是干嘛的？”是指哪讲哪（用按键百科，不调 AI）；要细说、要留下来的（点评、排计划、“写张小纸条”）它想几秒钟，递一张**小纸条**，可以收进**纸条本**（进度文件里的 `notes`）。纸条上的课号（1.2、5.1）、小课堂的关（T1、R2、F1）、“练习场”、按键（[REC SAMPLE]、SAMPLER、Drum key 5）能点：课和关直接跳过去，纸条跟着啾啾留着；按键是啾啾飞到机器的图上讲（这一页没有图就去面板页），讲完能“回到纸条”（`coach.js` 的 `linkify`；服务端人设要求 AI 课号写成“章.节”、按键用方括号）。样子、神态、动作、叫声的样稿页是 `/bird-lab.html`。它还藏着几个彩蛋（每天第一次打开、连续练习、小测全对、三星和升级时绕圈飞、掌握知识点叼羽毛回窝、连点 5 下会晕、在机器上弹一句它学舌、机器放久了跳舞、一再让它唱就吹口哨哼曲子），说话的口头禅是“早，啾！”这种——都记在 `docs/design-direction.md` 的“啾啾的彩蛋和口头禅”。啾啾的样子参考了 [huashu-bird-sticker](https://github.com/alchaincyf/huashu-bird-sticker)（花叔）里的红嘴相思鸟贴纸，按 CC BY 4.0 使用（设置页“关于啾啾”里有署名）。

两个引擎，在页面的「设置」里配置，只配一个也能用。**2026-11-13 起啾啾所有的回答都走即时引擎**（用户：“全都走即时引擎吧，我们也没什么特别难的问题”）；深度引擎只在即时引擎没配好或连不上时顶上。实测（Mac，即时引擎 deepseek-flash-256k）：简单问题 1–4 秒说完，“今天怎么练”的计划纸条约 3 秒，写成小纸条约 4 秒，按弱点出题约 2 秒；同样的计划走深度引擎要 24 秒左右。

| 引擎 | 用途 | 来源 |
|---|---|---|
| 即时 | 现在全部：问答（一句一句地说）、点评、排计划、小纸条、按弱点出题 | DeepSeek / Kimi 等 OpenAI 兼容接口，需要填 API key |
| 深度 | 备用：即时引擎没配好或连不上时由它回答（慢，十几到二十几秒） | 本机已登录的 Codex CLI（`codex exec`），不需要 key |

key 保存在项目根目录的 `config.local.json`（已在 `.gitignore` 里）。也可以用环境变量 `DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY`，或者让服务按变量名从一个 `.env` 文件里读（`config.local.json` 里的 `envFile`）。
这台机器上现在的即时引擎是自己部署的网关上的 `deepseek-flash-256k`（设置页服务商里的“Knight AI 网关（DeepSeek 256K）”，地址和 key 从 `../llm.env` 读）；为什么是它、和 DeepSeek 官方接口比快慢如何，见 `docs/model-comparison.md`。改了服务端的代码或 `config.local.json` 之后要重启服务才生效：在 Mac 的终端里运行 `zsh tools/restart-server.sh`（停掉 4747 上的旧服务、在后台重新起一个，日志追加到 `server.log`）。注意 Mac 上现在的正式服务不在哪个终端窗口里，是在后台跑的，所以“在窗口里按 Ctrl+C”停不了它；双击 `start.command` 看到服务已经在跑，也只会打开页面、不会重启。
教练的“机器操作知识”来自 `docs/coach-knowledge.md`，改了它不用重启。

## 现状（第一阶段）

- 已完成：应用框架、SEQTRAK 连接与状态读取、音游引擎、AI 双引擎、第 0–8 章共 35 节课、练习场 24 个谱面、27 首曲目候选（2026-11-11 先换成用户听过的 11 首，后来又按他的要求加了 16 首排行榜热门，五种风格）。
- **第 3 章「和弦与和声」**（`content/ch3.js`，4 节课）：3.1 三个音叠在一起 → 3.2 机器的 CHORD 弹法，把 SYNTH 2 和 DX 调成和弦手 → 3.3 给第 2 章的贝斯盖上和弦（步进输入放和弦、把音拉长）→ 3.4 把乐句加长到两小节装下四个和弦，再用两首歌的和弦进行练手。为它新增的：
  - 音游多了“和弦谱面”（一条轨道 = 一个 Synth key 的和弦；练习场的“和弦”“歌里的和弦”两组，共 6 个）。真机上一个键会一口气发出好几个音，引擎把紧挨着的一串算成一次按键。
  - 模拟机补了：三种弹法（MONO / POLY / CHORD）、把和弦放进格子、按住步进键改音长或换和弦、[BAR LENGTH] 加长到 2 小节、[PAGE] 翻页。
  - 真机镜像多认了几样：三条合成器轨各自的弹法、乐句有几小节、右边 4 个旋钮在第几页、几个音一起响；换音色之后还会把**音色的名字**读出来显示（机器没有屏幕）。“切到 CHORD”“加长到 2 小节”这两样自动打勾，旁边各有一个“让应用替你设”的按钮。合成器轨的步进内容、在不在步进输入里、翻到第几页、音长仍然读不出，这些任务要自己点“做好了”。
  - 3.4 的两个“歌里的和弦”练习和练习场那一组，2026-11-12 换成了用户听过的歌（原来的 Sweet Dreams、Still D.R.E.、Clint Eastwood 他没听过）：**Gangsta's Paradise**（原曲就在 C 小调，键 6 → 4 → 5 → 1）、**Starboy**（键 1 → 7 → 6 → 7，一小节一个，正好是 3.4 开头那个预设）、练习场另有 **Something Just Like This**（键 6 → 7 → 1 → 7）。和弦和曲目分轨里这几首一致，都搬到了 C 小调、用机器现成的 7 个和弦，是简化版。
  - 开工前在真机上测过的（弹法存在哪、它跟着音色走、和弦内容、乐句长度、音色名）和**还没有人在机器上按过键验证的**（CHORD 下按一个键 USB 上具体出来什么等），都在 `docs/hardware-findings.md` 的最后一节。整章在模拟机和假真机上逐步走通过（`dev/walk-ch3.js` 可以重放；`tools/mac-check.sh` 每次会在 Mac 的 Chrome 里自动走没有音游的 3.1 和 3.3），用户还没上过这四节课。
- 屏幕上有一台可操作的模拟 SEQTRAK（`simulator.js`）：左边导航栏的「面板」页是按键百科（自由探索 / 导览 / 找按键 / 灯色速查），课程的每个“动手”步骤也带着它，没接真机时可以完整地在上面学。第一课（0.1）从第二步起就让学生把真机接上：导览和“动手摸一遍”都对着真机镜像做，没带机器的人跳过连接那一步，在模拟机上学。
- 接着真机时，这台模拟机会换成**真机镜像**（`mirror.js`）：你在机器上按什么，屏幕上就亮什么，并有一句解说；课程的“动手”和鼓轨的“编程挑战”直接看真机的状态自动打勾，做偏了会提示（选错轨道、还差第几步、转到了另一段乐句、还停在演示曲上）。「面板」页的「真机镜像」里还有机器当前状态、一张可以照着试的清单和操作记录。音游（练习场和课程里的“练习”）也带着它（`game-mirror.js`）：开打之前有一张检查卡片（机器停着没有、打鼓模式开了没有；弹贝斯时看选没选中合成器轨、音阶和调对不对，不对可以点一下替你设好），并列出这个谱面用到的是哪几个 Synth key；打的时候你敲哪个键，舞台旁边那面镜子上哪个键就亮，这期间不定时查询机器。它靠机器主动上报的消息加上每 0.3 秒读一遍机器状态实现，只读不写；单独按 [DELETE] / [MUTE] / [SOLO] / [PAGE]、合成器轨的步进内容还读不出来。
