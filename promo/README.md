# SEQTRAK Academy 宣传片

发 B 站用的产品宣传片：1920 × 1080、60 帧、约 64.5 秒，没有旁白。2026-11-21 和用户一起定的方向，改了三版：

- **风格「一层层叠起来」**：音乐跟着学习路线一层层往上叠（鼓 → 贝斯 → 和弦 → 旋律 → Drop），每加一层切一个功能画面，最后整首爆发，收在开屏的“按 PLAY”上。
- **第二版的意见**：开场要有冲击力（节奏由慢到快、跟着鼓跳的频谱）；字幕要产品介绍的口吻，不要教学味；文字动效要有冲击力；片尾啾啾的气泡被切顶。
- **第四版的意见**：开头那几声鼓配的画面（一颗键、炸开的频谱）不好，不要了，改成用鼓声把产品名称这一页逐渐引入。
- **第三版的意见**：前面的鼓太长、拖沓，开头除了鼓不要别的声音；前半段观众不知道片子在讲什么，对产品的提示不足（鼓 → 贝斯 → 旋律的递进、后半段都保留）。
  按设计资料里的 video-shotcraft（宣传片骨架、审美准则）改成：**先亮品牌**（标志、片名、定位一句、四个功能标签），主角镜头交代“为 SEQTRAK 打造”，三个功能各 2 小节；
  整画面的白闪只留三处、不震屏、背景不跟拍泵，要读的字至少 56 像素、辅助文字至少 32 像素，同一信息全片只出现一次。
- **音乐是原创的**，从应用开屏（`public/js/splash.js`）那段 120 BPM、D 大调的律动长出来，全部用应用自己的合成器（`public/js/audio.js`）和啾啾的叫声（`public/js/bird-voice.js`）现场算，不带任何音频文件，也没有版权问题。
- **画面**：代码动画（直接用应用里的啾啾 `bird.js`、机器面板 `device-panel.js`、小课堂封面 `classroom-covers.js`）+ 真实界面的截图（Drop 段）+ 从真音频算出来的频谱。
- **配色**：霓虹为主，Drop 的后半卡点切到机身。
- **标语**「按下 PLAY，玩出第一首歌」（第四版之后换的，接片尾按 PLAY 的画面；最早是「从一声“咚”，到一首歌」，开头改版后接不上了）；片尾只有片名和标语，加一行啾啾形象的署名（CC BY 4.0 要求）。

## 怎么预览

```
node promo/serve.mjs
```

然后用 Chrome 打开 <http://127.0.0.1:4790/promo/>：点 ▶ 或按空格放（带声音），拖进度条，点下面的段名跳过去，← → 一次跳一小节（按住 Shift 跳四小节）。地址加 `?t=36.5` 直接停在某一秒。

## 怎么改

- 时间：全部按小节算，`js/time.js` 的 `at(小节, 拍, 格)`；前奏的长度是 `INTRO`（第 1 小节从它后面开始），前奏里三下心跳的时刻是 `score.js` 的 `HEART`；分段在 `SECTIONS`。
- 音乐：`js/score.js`（谱），`js/music.js`（混音：各路音量、混响、蓄力的高通、Drop 里的“压一下”）。
- 字幕：`js/captions.js`（`[方括号]` 里的字是桔红的重点词；进场、出场的动效在 `engine.js` 的 `createCaptions`）。
- 频谱：`js/spectrum.js`。它是从渲染出来的真音频算的（`promo/out/spectrum.bin`），改了音乐要先跑一遍 `node promo/render.mjs --audio` 预览里的频谱才会跟上；没有这个文件时用按底鼓编的假频谱。啾啾在哪、什么神态、说什么：`js/bird-track.js`。
- 每一段的画面：`js/scenes/`（brand 是 A+B，game C，mirror D，theory E，bird F，keys G，drop H，end I）。样式都在 `promo.css`，颜色只用 `public/css/app.css` 的变量。

## 怎么渲染

需要 Chrome 和 ffmpeg（`pip install imageio-ffmpeg` 就有一个，或者用环境变量 `FFMPEG` 指定）。在仓库根目录：

```
node promo/make-data.mjs        # 生成截图用的演示进度（promo/data/progress.json，已经生成好了）
node promo/capture.mjs          # 截真实界面 → promo/shots/（另起临时服务，不碰 data/ 里的真实进度）
node promo/render.mjs           # 渲染 → promo/out/seqtrak-academy-promo.mp4（约 7 分钟；先算音频和频谱，再逐帧截图）
```

检查用：`node promo/peek.mjs 12.3 36.5`（截几秒看版式）、`node promo/peek.mjs --sheet 0:78:2`（每 2 秒一张的总览）、`node promo/render.mjs --mix`（分别量鸟叫、音乐各段的响度）、`node promo/render.mjs --from 36 --to 48`（只渲一段）。

渲染的原理：`/promo/?render` 把页面里的时间换成“假时钟”（`js/vclock.js`：定时器、rAF、网页动画都按帧走），一帧一帧拨、截图、喂给 ffmpeg，所以每次渲出来都一模一样，不会掉帧；音频用 OfflineAudioContext 一口气算完（`/promo/?audio`）。
